# Glossary

> This document is bilingual. English content comes first, and a Korean summary appears later in the file.
> 이 문서는 영어와 한국어를 함께 제공합니다. 영어 본문이 먼저 나오고, 뒤쪽에 한국어 요약이 이어집니다.

## Surface

A declared product screen or screen-like workflow boundary.

## Zone

A named adaptive region inside a surface.

## Variant

A pre-approved rendering option for a zone.

## Adaptation Plan

The runtime output that describes which variants and token overrides were selected and why.

## Explicit Preference

A direct user-selected setting that overrides learned inference.

## Learned Preference

A deterministic numeric preference inferred from aggregated behavior signals.

## Stability Guard

A rule that prevents frequent or unsafe UI switching.

## Why Trace

The explainability payload describing why a plan was selected.

## 한국어 요약

- `Surface`: 하나의 화면 또는 작업 경계
- `Zone`: surface 안의 적응 가능한 영역
- `Variant`: zone에서 허용된 렌더 옵션
- `AdaptationPlan`: 어떤 variant와 token이 왜 선택됐는지 담는 결과
- `Explicit Preference`: 사용자가 직접 고른 설정
- `Learned Preference`: 행동 집계로 추정한 수치형 선호
- `Stability Guard`: UI 흔들림을 막는 규칙
- `Why Trace`: 선택 이유를 설명하는 trace 데이터
