# Adaptive UI Interface System

- Direction: Data & Analysis
- Foundation palette: cool neutral surfaces, restrained blue accent, semantic green/red feedback
- Depth strategy: borders-first with selective soft shadow for floating devtools only
- Corner language: subtle 10px radius for app surfaces, 12px for overlays
- Spacing scale: 4px base with 8px rhythm on major layout groups
- Type scale: compact UI text, strong numeric emphasis, consistent tabular number usage
- Motion profile: fast-subtle with reduced-motion compliance and conservative transitions
